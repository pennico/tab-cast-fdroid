# Tab Cast — update site

Update site for Tab Cast (tablet) and Tab Cast TV. It holds no source code: that is at
https://github.com/pennico/tab-cast (GPL-3.0-or-later).

- `repo/`: an F-Droid repository with the signed **Tab Cast** and **Tab Cast TV** APKs and the signed index. Both
  apps update themselves from it (and any F-Droid client can read it):

      https://pennico.github.io/tab-cast-fdroid/repo

  Check the repository fingerprint against the one you were given.
